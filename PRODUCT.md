# Altura Gráfica IA

Altura Gráfica IA reúne ampliación, eliminación de fondo y extensión de lienzo en un taller digital accesible. El usuario carga una imagen, configura una operación, comprende el estado y descarga el resultado. La aplicación mantiene autenticación Firebase, créditos y administración, y usa Laravel/PostgreSQL como autoridad de negocio.

El producto está orientado a Windows, Android y web mediante una PWA responsive en español. No se inventan porcentajes de progreso: se comunica una fase reconocida o actividad indeterminada.
